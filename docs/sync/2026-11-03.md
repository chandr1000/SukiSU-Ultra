## 3. Bootstrap (one-time, conflict-free)

Run on `main`. The merge carries **no content change** (`-s ours`) and resets the
future merge-base to `28db74f6`, so every subsequent Phase 2 cycle is a small,
mostly clean merge of fresh `ksu/main` deltas:

```bash
git fetch ksu
git switch main            # should be at ea9f31bb (or later)
git merge -s ours --no-ff ksu/main -F /tmp/bootstrap-msg.txt
git push origin main
```

Merge message (`/tmp/bootstrap-msg.txt`):

```
Merge ksu/main (28db74f6) as ours-baseline — Path 2 bootstrap (§10)

The SukiSU main lineage last absorbed KernelSU content on 2025-03-09
(merge-base 203cd4d7); SukiSU squash-syncs, so a direct ancestor merge
now measures 464 conflicted paths (dry-run 2026-11-03, docs/sync/).

This merge declares the current main tree as the semantic baseline and
carries NO content change (-s ours). The 847 skipped ksu commits are
re-introduced deliberately via the absorption ladder (topic batches:
uapi/supercall -> hook -> ksud protocol -> policy/identity ->
feature/core), tracked in docs/sync/absorption-audit-847.txt.

Effect: future Phase 2 cycles merge small ksu/main deltas cleanly
(new merge-base = 28db74f6).
```

Post-merge checks:

```bash
git diff HEAD^1 HEAD --stat        # empty — tree unchanged by the merge
git merge-base main ksu/main       # = 28db74f6
```
